预期现象

  • GET 健康检查：服务端正常返回 JSON，其中 body 为 "" —— 无请求体，'data' 不触发。
  • 表单提交 POST：请求不受 CORS 限制，一定到达服务端 → 'data' 触发 → push('2121') 推入字符串 → 'end' 里 Buffer.concat 抛 TypeError，进程崩溃。页面无响应属预期。
  • fetch POST：请求到达 → 同样触发 TypeError、连接被重置；若立刻失败且 Node 终端毫无动静，说明被浏览器预检(CORS/PNA)拦截，改用表单提交。
  • 崩溃后重启：node day02/createServer.ts
